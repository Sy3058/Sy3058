## Projects

### [Let's Git It!](https://github.com/git-going-cat/Lets-Git-It) · Git 학습 타이핑 게임

프론트엔드 리드로 React와 Phaser의 역할을 나누고, 실시간 게임 화면의 상태와 이벤트 흐름을 설계했습니다. 사용자 행동을 측정해 튜토리얼을 개선했고, 완료율은 **60% → 77%**로 높아졌습니다. Git 명령어를 맥락 속에서 익히는 AI 학습 모드도 구현했습니다.

`React` `TypeScript` `Phaser` `TanStack Query` `PostHog` · [프로젝트 README](https://github.com/git-going-cat/Lets-Git-It#readme)

### [LIVErary](https://github.com/LIVErarian/LIVErary) · 실시간 독서 모임

프론트엔드 1명, 백엔드 5명인 팀에서 프론트엔드 구조를 맡았습니다. 공통 컴포넌트와 UI 조립 규칙을 마련해 백엔드 팀원들이 담당 API와 연결된 화면을 함께 구현할 수 있게 했습니다. WebRTC 음성 통신과 PixiJS 화면, WebSocket 아바타 동기화를 연결했습니다.

`React` `TypeScript` `WebRTC` `WebSocket` `PixiJS` · [프로젝트 저장소](https://github.com/LIVErarian/LIVErary)

### [StockQ](https://github.com/Sy3058/StockQ) · 산업·기업 데이터 시각화

산업 간 관계를 방사형 인사이트 맵으로 탐색하고 기업의 재무 지표·뉴스를 함께 살펴보는 프로젝트입니다. **공개 저장소에는 2026년 4월 3일자 프론트엔드 코드 일부를 복구**했으며, 현재는 예시 데이터로 화면을 확인할 수 있습니다. D3 기반 맵, 지표 비교 화면, 커서 기반 기업 목록 등 복구된 구현 범위는 [README](https://github.com/Sy3058/StockQ#readme)에 정리했습니다.

`React` `TypeScript` `D3` `TanStack Query` `Jotai` · [복구된 프론트엔드 코드](https://github.com/Sy3058/StockQ)

`Vue 3` `TypeScript` `Pinia` `Kakao Maps API` · [프로젝트 README](https://github.com/Sy3058/Roll-Into-Korea#readme)

`Astro` `React` `TypeScript` `FastAPI` `PostgreSQL` · [README와 구현 보기](https://github.com/Sy3058/d-web#readme)
